SALTO ESTELAR - APP ANDROID
==========================

El código fuente de la aplicación está en esta carpeta. Requiere Android Studio,
Android SDK Platform 36 y un teléfono Android 13 (API 33) o posterior.

La aplicación abre primero https://salto-estelar.onrender.com/ para acceder a
cuentas, progreso compartido, salas online y videollamadas. Si no hay conexión,
carga la copia local incluida para jugar individualmente. La cámara y el
micrófono se solicitan solo cuando se activan las llamadas.

COMPILAR EL APK

1. Abre la carpeta app en Android Studio.
2. Espera a que Gradle sincronice el proyecto.
3. Selecciona Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Android Studio mostrará la ruta del APK generado.

También puedes usar el script de PowerShell `build-apk.ps1` desde esta carpeta
si Gradle y Android SDK están configurados en el equipo.

La base de datos en Render debe estar conectada y activa para crear cuentas.
La cámara y el micrófono dependen de HTTPS, permisos Android y de que la red
permita WebRTC. Consulta el README del proyecto para los límites del plan gratuito.
